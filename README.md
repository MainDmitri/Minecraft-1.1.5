# MCPE 1.1.5 Client

Сетевой клиент для Android (Flutter) для серверов Minecraft: Pocket Edition 1.1.x (протокол 113).
Код написан с нуля по открытым описаниям протокола; кода и ресурсов Mojang в проекте нет.

## Что умеет

- Опрос сервера без входа: MOTD, версия, протокол, онлайн, пинг.
- Подключение по RakNet (UDP): надёжная доставка, разбитые пакеты, ACK/NACK, пинг.
- Вход без Xbox Live: самоподписанная JWT-цепочка (ES384), скин 64×32 или 64×64 (стандартный или свой PNG).
- Шифрование соединения (ECDH P-384 + AES-256-CFB8), если сервер его включает.
- Чат с цветами `§`, перевод системных сообщений сервера.
- Команды 1.1 (`CommandStepPacket`): разбор по описанию команд с сервера, список команд с подсказками.
- Состояние игрока: здоровье, голод, уровень, координаты, режим игры, время в мире.
- Список игроков, заголовки и подсказки на экране, экран смерти с возрождением.
- Перенаправление на другой сервер (`TransferPacket`) и переподключение.
- 3D-мир: чанки с сервера, цветные блоки (без текстур Mojang), туман, другие игроки с никами.
- Управление: джойстик, обзор пальцем, прыжок и автопрыжок, плавание, полёт в творчестве.
- Ломание блоков (в выживании — с временем ломания от сервера), установка блоков, хотбар, блоки из творческого инвентаря.
- Чат прямо в 3D: сообщения сервера видны сразу после входа (например, просьба зарегистрироваться), поле ввода для команд вроде `/register`.
- Локальные миры: генерация рельефа с водой, пляжами, деревьями и рудами по зерну, режимы творчества и выживания, сохранение на телефоне.
- Свой сервер: мир можно открыть по сети — друзья в той же Wi-Fi сети заходят по IP телефона (порт 19132).
  Встроенный сервер работает по протоколу 113: команды `/help`, `/list`, `/time`, `/gamemode`, `/tp`, `/say`, `/seed`, `/setworldspawn`.

## Ограничения

- Блоки рисуются цветами, без текстур. Неполные блоки (ступени, плиты, заборы) рисуются целыми кубами.
- Мобы и предметы на земле не отображаются, инвентарь (кроме хотбара) и крафт не реализованы.
- Нет входа через Xbox Live: работают только серверы, где проверка Xbox выключена (`xbox-auth=false`).
- Только IPv4.
- Встроенный сервер упрощённый: нет урона, голода, мобов, крафта и инструментов; руды выпадают сами собой.
- Встроенный сервер проверен с этим клиентом; с официальным клиентом MCPE 1.1.5 не проверялся.
- Для игры через интернет нужен проброс UDP-порта на роутере; поиск мира в «Друзьях» MCPE может не работать на некоторых телефонах — вход по IP работает.

## Проверка

- Протокол проверен на сервере Nukkit 1.1.3 (протокол 113): вход, чат, команды, смерть и возрождение, отключение,
  ходьба, ломание и установка блоков (изменения сохраняются на сервере).
- Встроенный сервер проверен тестом: два игрока, чат, блоки, выживание, сохранение после перезапуска.
- Шифрование и подписи JWT сверены с реализацией из JDK (`AES/CFB8`, `ECDH`, `SHA384withECDSA`).
  С настоящим сервером 1.1, который включает шифрование, оно не проверялось.
- Юнит-тесты: `flutter test`.

## Сборка

```bash
git clone -b claude/minecraft-pe-1-1-5-source-34sfjv https://github.com/MainDmitri/Minecraft-1.1.5.git
cd Minecraft-1.1.5
flutter pub get
flutter run
flutter build apk --release
```

APK: `build/app/outputs/flutter-apk/app-release.apk`.
Готовый APK собирается автоматически: вкладка **Actions** → последний запуск **Build APK** → **Artifacts**.
