# MCPE 1.1.5 Client

Сетевой клиент для Android (Flutter) для серверов Minecraft: Pocket Edition 1.1.x (протокол 113).
Код написан с нуля по открытым описаниям протокола; кода и ресурсов Mojang в проекте нет.
Текстуры, звуки и скин Стива приложение берёт из вашего собственного файла игры (см. «Текстуры и звуки»).

## Что умеет

- Опрос сервера без входа: MOTD, версия, протокол, онлайн, пинг.
- Подключение по RakNet (UDP): надёжная доставка, разбитые пакеты, ACK/NACK, пинг.
- Вход без Xbox Live: самоподписанная JWT-цепочка (ES384), скин 64×32 или 64×64 (стандартный или свой PNG).
- Шифрование соединения (ECDH P-384 + AES-256-CFB8), если сервер его включает.
- Чат с цветами `§`, перевод системных сообщений сервера.
- Команды 1.1 (`CommandStepPacket`): разбор по описанию команд с сервера, список команд с подсказками.
- Состояние игрока: здоровье, голод, уровень, координаты, режим игры, время в мире.
- Список игроков, заголовки и подсказки на экране, экран смерти с возрождением.
- Перенаправление на другой сервер (`TransferPacket`) и переподключение.
- 3D-мир: чанки с сервера, туман, другие игроки с никами; с импортированными текстурами — блоки как в игре,
  трещины при ломании, солнце и луна с фазами, ночью мир темнеет. Без текстур блоки рисуются цветами.
- Интерфейс в стиле MCPE (хотбар, сердца, крестовина, кнопки из `gui.png`/`icons.png`), полноэкранный режим.
- Звуки из файла игры: ломание и установка блоков, шаги, удары по блоку, урон, подбор предметов, щелчок кнопок.
- Инвентарь как в Minecraft (кнопка «•••» у хотбара): броня, игрок со скином, крафт 2×2, 27 слотов и хотбар.
  Касание — взять/положить стопку, удержание — взять половину или положить один предмет,
  касание вне окна со стопкой — выбросить. Удержание слота хотбара в игре тоже выбрасывает стопку.
- Крафт по рецептам сервера (CraftingDataPacket): 2×2 в инвентаре, 3×3 на верстаке; удержание результата — крафт сразу на стопку.
- Сундуки и печи (окна сервера), броня, выпавшие предметы в мире и их подбор, износ инструментов.
- Управление: джойстик, обзор пальцем, прыжок и автопрыжок, плавание, полёт в творчестве.
- Ломание блоков (в выживании — с временем ломания от сервера), установка блоков, хотбар, блоки из творческого инвентаря.
- Чат прямо в 3D: сообщения сервера видны сразу после входа (например, просьба зарегистрироваться), поле ввода для команд вроде `/register`.
- Локальные миры: генерация рельефа с водой, пляжами, деревьями и рудами по зерну, режимы творчества и выживания, сохранение на телефоне.
- Свой сервер: мир можно открыть по сети — друзья в той же Wi-Fi сети заходят по IP телефона (порт 19132).
  Встроенный сервер работает по протоколу 113: команды `/help`, `/list`, `/time`, `/gamemode`, `/tp`, `/say`, `/seed`,
  `/setworldspawn`, `/give <ID> [количество] [мета]`.
  На нём работают: около 180 рецептов (доски, верстак, сундук, печь, все инструменты и броня, блоки, плиты, ступеньки,
  шерсть, факелы и др.), печь с топливом и переплавкой, сундуки (сохраняются), выпадение предметов с учётом
  инструмента (камень и руды — только киркой нужного уровня), время ломания по формуле Minecraft, износ инструментов.

## Текстуры и звуки

На главном экране — «Текстуры из файла игры»: выберите APK Minecraft PE 1.1.x или zip-архив с его ресурсами
(внутри должна быть папка `resource_packs/vanilla` с `blocks.json`). Приложение собирает из него:

- атлас блоков по `blocks.json` и `textures/terrain_texture.json`;
- `textures/gui/gui.png`, `textures/gui/icons.png` — интерфейс;
- `textures/environment/destroy_stage_0..9`, `sun.png`, `moon_phases.png` — трещины, солнце, луна;
- `textures/entity/steve.png` — кнопка «Скин Стива из файла игры» рядом с выбором скина;
- `sounds/dig`, `sounds/step`, `sounds/random/{click,glass1-3,hurt}.fsb` — звуки (FSB5 FADPCM перекодируются в WAV).

Всё сохраняется только на телефоне, в папке приложения.

## Ограничения

- Неполные блоки (ступени, плиты, заборы) рисуются целыми кубами, освещения от факелов нет.
- Мобы и предметы на земле не отображаются, инвентарь (кроме хотбара) и крафт не реализованы.
- Нет входа через Xbox Live: работают только серверы, где проверка Xbox выключена (`xbox-auth=false`).
- Клиент говорит на протоколе 113: сервер другой версии отклоняет вход («Login timeout», «Outdated client»),
  и подмена типа устройства (Windows 10 и т. п.) этого не меняет.
- Только IPv4.
- Встроенный сервер упрощённый: нет урона, голода и мобов; двери, кровати, вёдра и семена нельзя поставить;
  еда не съедается.
- Встроенный сервер проверен с этим клиентом; с официальным клиентом MCPE 1.1.5 не проверялся.
- Для игры через интернет нужен проброс UDP-порта на роутере; поиск мира в «Друзьях» MCPE может не работать на некоторых телефонах — вход по IP работает.

## Проверка

- Протокол проверен на сервере Nukkit 1.1.3 (протокол 113): вход, чат, команды, смерть и возрождение, отключение,
  ходьба, ломание и установка блоков (изменения сохраняются на сервере).
- Встроенный сервер проверен тестом: два игрока, чат, блоки, выживание, сохранение после перезапуска.
- Инвентарь проверен сквозным тестом клиент ↔ встроенный сервер: крафт 2×2 и 3×3 (верстак), перенос стопок,
  броня, сундук, переплавка в печи, выброс и подбор предмета, сохранение после перезапуска.
  Форматы пакетов инвентаря сверены с исходниками PocketMine-MP и Nukkit для протокола 113.
- Шифрование и подписи JWT сверены с реализацией из JDK (`AES/CFB8`, `ECDH`, `SHA384withECDSA`).
  С настоящим сервером 1.1, который включает шифрование, оно не проверялось.
- Импорт ресурсов проверен на архиве ресурсов MCPE 1.1 (428 текстур, 73 звука); декодер FADPCM сверен с vgmstream побитно.
- Юнит-тесты: `flutter test`.

## Сборка

```bash
git clone -b claude/minecraft-pe-1-1-5-source-34sfjv https://github.com/MainDmitri/Minecraft-1.1.5.git
cd Minecraft-1.1.5
flutter pub get
flutter run
flutter build apk --release
```

APK: `build/app/outputs/flutter-apk/app-release.apk`.
Готовый APK собирается автоматически: вкладка **Actions** → последний запуск **Build APK** → **Artifacts**.
